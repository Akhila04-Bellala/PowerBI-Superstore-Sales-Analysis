# Superstore Sales Analysis — Data Visualization and Storytelling

## Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Power BI. The goal is to transform raw sales data into meaningful visualizations and business insights that support better decision-making.

## Objective
To create an interactive and visually appealing dashboard that communicates sales performance, profitability, regional performance, customer segments, and top-performing products.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- CSV Dataset

## Dataset
**Dataset:** Sample Superstore Dataset

The dataset contains sales-related information, including orders, products, categories, regions, customer segments, sales, discounts, and profits.

## Key Performance Indicators (KPIs)
- Total Sales: Approximately $2.30M
- Total Profit: Approximately $286.40K
- Total Orders: 5,009
- Total Quantity Sold: 37,873

## Visualizations Created
1. Sales by Product Category
2. Profit by Region
3. Monthly Sales Trend
4. Sales by Customer Segment
5. Top 10 Products by Sales

## Key Business Insights
- The West region recorded the highest profit.
- The Central region recorded the lowest profit.
- The Consumer segment generated the highest sales.
- The business generated approximately $2.30M in sales and $286.40K in profit.
- The Top 10 Products chart identifies the products contributing most to sales.

## Project Files
- `Superstore_Sales_Analysis.pbix` — Power BI project file.
- `Superstore_Sales_Dashboard.pdf` — Exported dashboard report.
- `Sample - Superstore.csv` — Dataset used for analysis.

## Conclusion
This project demonstrates how data visualization and storytelling can turn raw business data into meaningful insights. The dashboard helps understand sales trends, profitability, regional performance, and customer segment contributions.
